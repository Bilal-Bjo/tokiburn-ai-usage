# Tokiburn identity

Tokiburn's mark is a compact usage ledger crossed by a descending burn
boundary. One coral cell identifies the current moment. The idea connects the
app's contribution field, persistent history, and cost-over-time model without
using literal fire, clocks, currency, or AI clichés.

The direction was explored through Higgsfield CLI with Recraft V4.1, then
rebuilt as exact geometry so every shipped size is deterministic.

- Selected Higgsfield job: `76185546-8db1-4dc3-a77a-e9c4740be499`
- Source mark: `Tokiburn-Mark.svg`
- App icon master: `Tokiburn-AppIcon-Master.png`
- Palette: graphite `#17181B`, paper `#F4F1EC`, signal coral `#FF6248`
- Exclusions: text, letters, flames, clocks, currency, robots, brains, arrows,
  gloss, gradients, and 3D rendering

Run `swift scripts/generate-app-icon.swift` from any directory to regenerate
the 2048px master and every required macOS asset-catalog size.
